# MAKEEN (مَكِين) — نظام نقاط البيع

نظام نقاط بيع متكامل مبني على Next.js: إدارة المبيعات والمخزون والكاشير والفروع،
مع مزامنة دون اتصال عبر IndexedDB، وطابعات حرارية، ولوحة تحكم متجر كاملة.

## الأوامر

```bash
npm run dev            # التطوير
npm run build          # بناء الإنتاج
npm run start          # تشغيل الإنتاج
npm run lint           # فحص الكود
npm run migrate        # تطبيق قواعد البيانات
npm run verify         # فحص شامل (api + security + hardware + store)
npm run verify:e2e     # تدقيق دورة الحياة الكامل
```

## الملاحظات

- لا يُحظر البيع عند مخزون صفر أو سالب — يسمح النظام للمخزون بالانخفاض إلى
  أرقام سالبة، ويمكن للمدير تصحيحها عبر جرد فعلي من لوحة التحكم (نواقص المخزون).
- شعار التطبيق في `public/logo.png`.
